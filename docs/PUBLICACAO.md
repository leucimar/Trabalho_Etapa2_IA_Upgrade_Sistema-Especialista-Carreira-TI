# Histórico de integração

## Organização

A implementação foi desenvolvida no repositório privado `leucimar/RepositorioTemporario` e integrada em etapas ao repositório oficial `leucimar/Atividade08-Construcao-Sistema-de-Carreiras-de-TI`.

A publicação das cinco etapas está concluída. `main` e `develop` contêm a versão completa. As branches `feature/01-conhecimento` até `feature/05-documentacao` preservam os marcos de cada grupo de funcionalidades.

No oficial, cada etapa corresponde a um novo commit de integração, aplicado após a etapa anterior. As branches foram avançadas por fast-forward, sem commits adicionais de merge e sem reescrever o histórico.
